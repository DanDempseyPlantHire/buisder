# DEASJobs v24.5 Brand Refresh

This release applies the supplied DEASJobs B logo across the app and public job pages.

## Brand implementation
- Uses the supplied logo as the in-app brand mark and PWA icon.
- New brand palette: Deep Black `#05070F`, Electric Cyan `#00E5FF`, Bright Blue `#2D7BFF`, Violet `#8B5CFF`, Graphite/Silver neutrals and white.
- Updates header, heroes, buttons, navigation, feed styling, authentication screens, analytics/growth/compliance panels, public jobs, legal pages and offline screen.
- PWA service-worker cache version bumped so existing installed users receive the refreshed assets.
- No D1 migration is required.
- Functions remain below the compact upload target.
