# Deas Jobs v25.1: Google Search Console Soft 404 mitigation

## What changed

- `public/index.html`: Public homepage remains in the HTML **after** JavaScript boots; it is no longer replaced with login-only content. Separate public landing intro and explanatory sections with crawlable links to `/jobs`, privacy, terms and young-user information.
- Signed-in users and the signup/reset flows hide the public landing while preserving the existing application views.
- If the backend bootstrap fails, the public homepage remains visible alongside the service message instead of reducing the page to an error screen.
- `public/404.html`: Real branded missing-page response. In Cloudflare Pages, including this file disables the default SPA catch-all behaviour that can otherwise respond `200` with `index.html` for unknown URLs. (Existing API/route Functions still control their own statuses.)
- Existing home canonical, WebSite/Organization structured data, `/jobs` public route, `robots.txt`, `sitemap.xml`, 301 old-domain redirect and all app features retained.
- No D1 migrations, R2 changes or Cloudflare credentials needed for this package.

## Deploy

1. Use GitHub Desktop. Replace repository contents with the full contents of this ZIP (preserve `.git`), commit and push to `main`.
2. In Cloudflare Pages, verify latest deployment succeeded and custom domain `deasjobs.com` is **Active**.
3. Check these URLs in a fresh/private browser tab: `https://deasjobs.com/`, `https://deasjobs.com/jobs`, `https://deasjobs.com/robots.txt`, `https://deasjobs.com/sitemap.xml`.
4. Open `https://deasjobs.com/some-nonexistent-page-test-20261019` and confirm it shows the branded **Page not found** page with HTTP 404. (Browser developer tools → Network → document → Status.)
5. In Search Console **URL Inspection** for `https://deasjobs.com/` choose **Test live URL**, then **View tested page**. Confirm the HTML/rendered screenshot shows the public job-platform text, HTTP 200, no `noindex`, correct canonical. If still blocked, inspect Googlebot accessibility, Cloudflare firewall/bot challenges, and the DNS/custom domain.
6. Submit `https://deasjobs.com/sitemap.xml`, and only if live test succeeds, request indexing.
7. Check site from signed-out and signed-in states: login, signup, password reset, job applications, employer job editing and admin controls.

## Important limits

A Google Soft 404 is a classification by Google, not an HTTP error we can force Google to clear. This package fixes a verified source-code issue that plausibly contributes to the problem. Live URL accessibility and Search Console results cannot be confirmed from the offline package. A changed report or inclusion in search results is not guaranteed.
