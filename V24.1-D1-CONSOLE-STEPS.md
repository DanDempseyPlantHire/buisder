# Buisder v24.1 D1 steps

Use `migration-free-launch-v24.1-d1-safe.sql`. It contains only the non-payment v24.1 features plus cleanup of payment-specific compliance entries.

In the Cloudflare D1 console, paste SQL only, not an `npx` command.

After running it, verify the 9 required v24.1 tables:

```sql
SELECT name FROM sqlite_master
WHERE type='table' AND name IN (
  'push_subscriptions','push_preferences','application_messages','message_reports','risk_flags',
  'integration_api_keys','integration_job_links','integration_events','matching_model_versions'
) ORDER BY name;
```

You should see 9 rows. Billing tables can remain if they were created by the earlier partial v24 attempt; they are dormant and are not required by this release.
