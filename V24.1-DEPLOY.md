# Deas Jobs v24.1 Free Launch deployment

1. Back up `buisder-db`.
2. Run `migration-free-launch-v24.1-d1-safe.sql`.
3. Verify the 9 non-payment v24.1 tables.
4. Deploy the complete v24.1 package via GitHub -> Cloudflare Pages.
5. Do not configure Stripe secrets or webhooks. If old Stripe secrets exist, remove them from the Deas Jobs Pages environment.
6. Configure VAPID public/private keys and subject for Web Push.
7. Deploy the included reminder Worker using the same D1 database and Resend/VAPID settings.
8. Run Admin -> Launch. There should be no Stripe/payment readiness check.
9. Test candidate, employer and admin workflows before inviting pilot users.
