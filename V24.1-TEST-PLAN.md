# Deas Jobs v24.1 Free Launch test plan

## Free-launch check
- No Billing tab appears in Admin.
- Employer Access page says the initial launch is free.
- No Subscribe, Buy featured placement, Manage billing or Stripe checkout buttons appear.
- `/api/billing/config`, `/api/billing/checkout`, `/api/billing/portal` and `/api/billing/webhook` are not deployed.
- Employer account deletion does not depend on a Stripe subscription.
- Terms and Privacy state that payment processing is disabled.

## Core regression
- Existing candidate, employer and admin accounts sign in.
- Candidate signup/profile/feed/apply/withdraw works.
- Employer verification/job posting/applicant workflow works.
- Interview/offer/hire workflow works.
- Public jobs/SEO routes work.
- Analytics, Growth, Pilot, Compliance and Risk pages load.

## Post-launch features
- PWA installs on Android and iPhone.
- Offline fallback works.
- Web Push can be enabled/disabled and arrives while app is closed.
- Scheduled reminder Worker creates due reminders.
- Matching reasons display without overlap.
- Application messaging/report/block works.
- Risk flags require human review and do not auto-reject.
- Employer API key is shown once and only its hash/prefix is stored.
- Stable external job ID updates the same job.
- ICS interview export opens in a calendar app.
