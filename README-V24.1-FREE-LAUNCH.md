# Buisder v24.1 Free Launch

This release keeps the v24 post-launch upgrades but removes payment functionality from the initial launch.

## Included
- Installable PWA and offline fallback
- Web Push notifications
- Scheduled interview reminder Worker
- Transparent job matching and match reasons
- Application-only messaging with report/block controls
- Human-review fraud/abuse risk flags
- Employer integration/API keys and job import/update surface
- ICS interview calendar export
- Existing public jobs/SEO, growth, pilot, analytics, privacy and compliance features

## Payment status
- No Stripe routes or helper module are deployed.
- No Admin Billing page.
- No employer checkout, subscriptions, paid featured jobs or billing portal.
- Employer access tiers are free capacity tiers during the initial launch.
- No referral cash, credits, points or financial rewards.
- Existing billing tables from a partial v24 migration may be left in D1; this release does not use them.
- Stripe can be reintroduced later as a separate release with updated Terms/Privacy before activation.
