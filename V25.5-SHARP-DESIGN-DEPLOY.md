# Deas Jobs v25.5 — Sharp-edge design update

**Full application release based on v25.4, with the same 72 Cloudflare Pages Functions files.**

## What changed

- Square corners replace rounded edges across buttons, input fields, job cards, feed tabs, navigation, badges, profile images, application panels, admin dashboards and modal sheets.
- Sharper visual hierarchy: solid high-contrast primary buttons, outlined cards, crisp blue/cyan accents, flat surfaces and clearer selection states.
- The public `/jobs` pages, individual vacancy and employer pages, legal pages, offline/404 pages, and email template controls adopt the same square design language.
- The **Deas Jobs** name and new circular logo artwork are unchanged. The supplied circular graphic sits within a square image frame; the image itself is not edited.
- Service worker cache bumped to `deasjobs-shell-v25.5-sharp` to encourage PWA asset refresh.
- All jobseeker, employer, account, admin, work-experience and SEO code is retained. No database changes required.

## Deployment instructions (GitHub Desktop / Windows)

1. Back up/commit your working GitHub repository first.
2. Extract the complete `Deas-Jobs-v25.5-Sharp-Design-Full-Release.zip` **outside** the cloned repository.
3. Open PowerShell in the extracted folder and run:

   `powershell -ExecutionPolicy Bypass -File .\INSTALL-V25.5-SHARP-CLEAN.ps1 -RepoPath "C:\path\to\your\DeasJobs-repo"`

4. The installer deletes only the old local `functions/` folder in that repository and replaces it with the 72-file folder, then copies the refreshed `public/` assets. It does not delete `.git`, D1, R2 or your Cloudflare configuration.
5. Review changes in GitHub Desktop. Commit and push to `main`.
6. In Cloudflare Pages, check that the deploy succeeds. Hard-refresh deasjobs.com. If installed as a PWA, close/reopen and refresh it; remove old site data only if cache persists.
7. Inspect: homepage/login/signup, Jobs and Work experience feeds, employer creation/editing, admin/analytics/compliance screens, modal dialogs, legal pages, `/jobs` and individual job pages.

## Validation

- 72 Functions files (under your 100-file target)
- No new backend API routes, new secrets, or D1 migration
- Syntax checks should pass for HTML inline app JavaScript, Functions JavaScript, and service worker before deploy
- Live Cloudflare/Google crawl and login flows require validation after deploying

**Do not merge Functions directories.** The clean installer replaces the old one to prevent historic routes accumulating in GitHub.
