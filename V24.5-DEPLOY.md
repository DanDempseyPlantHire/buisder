# DEASJobs v24.5 deployment

No D1 migration is required.

## Recommended deployment
1. Use the GitHub Desktop clone of the DEASJobs repository.
2. Replace the repository contents with this release, keeping the repository `.git` folder.
3. Commit with a message such as `DEASJobs v24.5 brand refresh`.
4. Push to `main`.
5. Wait for Cloudflare Pages to show a successful deployment.
6. Hard refresh the website once after deployment.
7. If testing the installed PWA, fully close and reopen it. The service-worker cache version was changed so the new logo and theme should replace the previous shell.

## Visible checks
- The top bar shows the supplied circular DEASJobs logo, not the old letter B tile.
- Login and signup show the logo inside the hero panel.
- Primary buttons use the cyan-to-blue gradient.
- Main background/navigation are deep black/navy with cyan/blue/violet accents.
- PWA / Home Screen icon uses the new logo.
- `/jobs` public pages use the new identity.
- Privacy, Terms, Cookies, Rights and Young Users pages use the new identity.
