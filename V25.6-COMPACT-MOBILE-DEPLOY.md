# Deas Jobs v25.6 — Compact iPhone layout

Full release based on **v25.5.1**; includes square-edged branding, work experience feeds and previous Google indexing improvements.

## Changes

1. **Less text:** Shortened the public homepage, login, swipe feed, employer dashboard, filters, settings descriptions and some analytics/support pages. Preserved legal/privacy and critical safety content.
2. **iPhone spacing:** Added a 10px top offset plus `safe-area-inset-top` for notched iPhones in the main app, public job pages and legal pages. The viewport already uses `viewport-fit=cover`.
3. **Full-width bottom tabs:** Removed fixed 76px tab widths and horizontal scroll for normal navigation; four jobseeker tabs and six employer tabs now divide the available bar width equally. Admin navigation uses an edge-to-edge four-column grid.
4. **PWA:** Bumped the cache version so an installed app can pick up the new layout.

## Deployment via GitHub Desktop (recommended)

1. Back up/commit your existing GitHub repository before applying the release.
2. Extract this full ZIP into a new directory outside the GitHub repository.
3. From the extracted directory, run PowerShell (substitute your actual repository path):

   `powershell -ExecutionPolicy Bypass -File .\INSTALL-V25.6-CLEAN.ps1 -RepoPath "C:\path\to\your\Deas-Jobs-repo"`

4. This **replaces** the repository's `functions/` folder instead of merging obsolete files; it copies the new `public/` files, preserving `.git`, unrelated files and Cloudflare database data.
5. In GitHub Desktop, review the changes and push to `main`. Confirm Cloudflare Pages builds successfully.
6. Refresh the website. For an installed iPhone PWA, close it completely and reopen it. If the old design remains, revisit after the service worker activates or clear the site's cached data as a last resort.
