# DEASJobs v24.3 test plan

## Passwords
- Create a test account with an 8-character password: succeeds.
- Try a 7-character password: rejected.
- Reset a password to 8 characters: succeeds.

## Employer plan hidden
- Employer bottom navigation has no Access/Plan tab.
- Employer dashboard has no plan card or Manage plan button.
- Employer can post multiple active jobs without a plan-limit error.
- Employer can reopen a paused/closed job without a plan-limit error.

## Admin permanent delete
- Admin -> Users shows Permanently delete account for non-admin users.
- Button opens a DELETE confirmation dialog.
- Wrong confirmation is rejected.
- Correct confirmation deletes the user.
- Deleted user disappears after reload and cannot log in.
- Admin accounts do not show the permanent-delete button.

## Production wording
- Browser title does not contain Prototype.
- End-of-feed wording does not describe jobs as placeholders.

## Reload jobs
- Apply to a job.
- Skip at least one other job.
- Press Reload jobs.
- Skipped job returns to the feed.
- Existing application remains in Applications and in the employer applicant list.

## Remove application
- Apply to a job.
- Open Applications and select Remove application.
- Confirm removal.
- Application disappears from the job seeker's visible list.
- Employer sees the application as Withdrawn.

## Swipe speed
- Swipe right and left repeatedly.
- Next card appears immediately rather than waiting for the API response.
- Failed request, if deliberately induced, restores the affected card and shows an error.

## Edit jobs
- Employer Dashboard -> Your jobs -> Edit job.
- Change title, location, pay, hours, work type, availability, experience, age, industry, start and description.
- Save.
- Reload and confirm changes persist.
- Confirm the edited job appears correctly in the candidate feed/public view.

## Work experience
- Employer posts a job with Work experience selected.
- Job seeker opens Filters -> Work type -> Work experience.
- Only Work experience roles remain where applicable.
- Job seeker can also save Work experience as Preferred work type in Profile.
