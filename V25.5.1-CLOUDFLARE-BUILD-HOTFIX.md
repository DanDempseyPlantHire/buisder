# Deas Jobs v25.5.1 — Cloudflare build hotfix

## What was fixed

Cloudflare Pages failed bundling v25.5 with `Expected ":" but found ";"` in `functions/_lib/email-notifications.js:135`.
The square-corner transformation had truncated the conditional "Open Deas Jobs" link in an email HTML template.
The same truncation affected the pilot invitation email in `functions/api/admin/pilot/[[path]].js`.

This hotfix restores both complete template-string expressions and retains `border-radius:0` on the links.
All other v25.5 source files remain unchanged. The website's square-edge design and the Deas Jobs logo are retained.

**Note:** Cloudflare's `No Wrangler configuration file found. Continuing.` is informational in this Pages setup and did not cause this failure.

## Installation — full release

1. Back up or commit the local GitHub clone.
2. Extract `Deas-Jobs-v25.5.1-Cloudflare-Build-Fix-Full.zip` outside the GitHub clone.
3. In PowerShell, run the following from the extracted folder, replacing the path with your GitHub repository path:

   `powershell -ExecutionPolicy Bypass -File .\INSTALL-V25.5.1-CLEAN.ps1 -RepoPath "C:\path\to\your\DeasJobs-repo"`

4. Open GitHub Desktop, review changes, commit and push to `main`.
5. Confirm the new Cloudflare Pages deployment succeeds. Test login, emails, job feeds and pilot invitation flow where applicable.

The installer **replaces**, rather than merges, the old `functions/` folder (72 files). It also copies `public/` assets. Do not delete `.git`.

## Installation — two-file patch

If v25.5 already exists completely in your repository, you may instead use `Deas-Jobs-v25.5.1-Two-File-Hotfix.zip` and replace only:

- `functions/_lib/email-notifications.js`
- `functions/api/admin/pilot/[[path]].js`

Do **not** replace the whole `functions/` directory with the two-file patch; those are only the changed source files.
