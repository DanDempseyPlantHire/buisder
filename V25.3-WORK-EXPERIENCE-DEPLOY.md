# DEASJobs v25.3 - Jobs and Work Experience

This is a **complete release**, based on v25.2, with **72 Cloudflare Functions files**.
It includes the earlier homepage Google Soft 404 mitigation and v25.2 compact API routes.

## Changes

### Employers
- Employer Dashboard: **Post work experience** button, separate from **Post a job**.
- Posting form: **Opportunity type** selects Job or Work experience.
- Work experience is saved using existing `employment_type = 'Work experience'` value. There is no new database column.
- On work experience forms, a reminder asks employers to clearly state whether paid, expenses covered, duration, and supervision. No assumption is made that the placement is unpaid.
- Employers can edit a listing and change between job and work experience; existing API route is reused.
- The employer dashboard clearly identifies work experience listings.

### Jobseekers
- Bottom navigation now has **Jobs**, **Work experience**, **Applied** and **Profile**.
- Jobs swipe feed excludes work experience placements.
- Work experience swipe feed excludes normal jobs; right swipe applies and left swipe skips using existing application controls.
- Both feeds share applications and skips, retaining existing safeguards against duplicate applications.
- Work experience view ignores regular-job minimum pay and employment type filters, so unpaid opportunities are not hidden by pay preferences. Other relevant filters such as distance, industry and age restrictions remain.
- Legacy saved `Work experience` filter settings are migrated to `Any` for the separate Jobs view.

### Public SEO
- `/jobs` has distinct, accessible **Jobs** and **Work experience** sections with links to each section.
- The existing canonical URL, sitemap, individual job pages, public visibility constraints and structured data are maintained.

## Deploy safely using GitHub Desktop

1. Back up/commit your current GitHub clone before starting. Make sure the current app is deployed.
2. Extract this **full release** to a new folder outside the GitHub clone.
3. In Windows PowerShell from the extracted folder, run:

   `powershell -ExecutionPolicy Bypass -File .\INSTALL-V25.3-CLEAN.ps1 -RepoPath "C:\path\to\your\DEASJobs-repo"`

4. The installer *replaces* the entire existing `functions/` directory (to remove stale routes) and copies the updated `public/` files. It does not delete `.git`, modify Cloudflare D1, or touch R2.
5. In GitHub Desktop review changes, commit and **Push origin** to `main`. Cloudflare Pages auto-deploys.
6. Verify Cloudflare deployment succeeded and hard-refresh the site, or restart the installed PWA.
7. Test with an employer account: Post work experience, edit the placement, and verify the correct label on your dashboard.
8. Test with a jobseeker account: switch between **Jobs** and **Work experience**, apply/skip, confirm applications remain under **Applied**, and verify age filtering.
9. Visit `https://deasjobs.com/jobs` and confirm separate public sections.

**Do not merge** a new Functions folder into an old one; this can leave more than 100 old/new files in GitHub.
