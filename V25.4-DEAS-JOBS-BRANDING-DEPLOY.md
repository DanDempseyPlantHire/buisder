# Deas Jobs v25.4 - Branding update

This is a complete release based on v25.3, with **72 Cloudflare Functions files**.
It keeps the separate **Jobs** and **Work experience** experience and the earlier Google indexing fix.

## Changes

- Replaced the logo with the new supplied **Deas Jobs** circular logo.
- Changed the visible product name from **DEAS Jobs / DEASJobs** to **Deas Jobs** across the app UI.
- Updated public branding in the homepage, sign-in area, legal pages, offline page and public jobs pages.
- Updated key metadata such as page titles, Open Graph, structured data and PWA name to **Deas Jobs**.
- Rebuilt app icons from the new logo.
- Kept the existing domain and technical asset paths as `deasjobs.com` / `deasjobs-logo.png` to avoid unnecessary deployment risk.

## Deploy safely using GitHub Desktop

1. Back up or commit your current GitHub clone before starting.
2. Extract this full release to a new folder outside the GitHub clone.
3. In Windows PowerShell from the extracted folder, run:

   `powershell -ExecutionPolicy Bypass -File .\INSTALL-V25.4-BRANDING-CLEAN.ps1 -RepoPath "C:\path\to\your\DEASJobs-repo"`

4. The installer replaces the entire existing `functions/` directory and copies the updated `public/` files.
5. In GitHub Desktop review changes, commit and push to `main`.
6. Let Cloudflare Pages deploy automatically, then hard refresh the site or restart the installed PWA.
7. Check the homepage, login area, public jobs pages, favicon/PWA install sheet and social preview branding.

**Do not merge** a new Functions folder into an old one. Replace it, or stale files can accumulate.
