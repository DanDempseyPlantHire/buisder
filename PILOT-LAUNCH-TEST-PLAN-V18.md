# DEASJobs v18 — Pilot Launch Test Plan

Use disposable test accounts for destructive tests.

## Candidate journey
- Create a new job-seeker account and complete Turnstile/email verification.
- Complete the profile and upload a photo/CV.
- Set availability, location and job preferences.
- View, skip and apply to jobs.
- Verify duplicate-application protection and application timeline.
- Withdraw a disposable application.
- Test Privacy Settings, report/block, data export and password reset.

## Employer journey
- Create and verify an employer account.
- Complete the business profile and submit business verification.
- Confirm plan limits.
- Post, pause, reopen and close a disposable job.
- Review and shortlist applicants.
- Invite to interview, complete interview, create an offer and complete the hire outcome.
- Test report/block and employer analytics.

## Admin journey
- Review business verification and a safety report.
- Suspend/restore a disposable user.
- Close/reopen a disposable job.
- Review Commercial and Analytics.
- Run Admin -> Launch preflight.
- Confirm maintenance actions are logged in the admin audit trail.

## Device/browser matrix
At minimum test current iPhone Safari, current Android Chrome, and current desktop Chrome or Edge. Check Turnstile, swipe gestures, bottom navigation/safe area, modal scrolling, file upload, interview date/time display, notifications, and admin tables/forms.

## Final pilot gate
Do not mark the manual checklist complete until a production D1 backup exists, no critical automated preflight checks remain, the full recruitment workflow has been tested, support/escalation is defined, and the pilot Terms/Privacy Summary have been reviewed for the controlled pilot.
